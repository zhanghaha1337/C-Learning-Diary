## 重点
1. 线性表：数据元素呈一对一的线性关系排列
2. 顺序表：依靠**连续数组**存储，内存地址连续
3. 顺序表结构体 = 数据数组 + 当前有效长度
4. 优点：随机下标访问速度快
5. 缺点：中间插入/删除效率低，容量固定

## 今日练习代码（顺序表基础实现）
```c
#include <stdio.h>
#define MAXSIZE 100

// 定义顺序表结构体
typedef struct {
    int data[MAXSIZE];
    int length;
} SqList;

// 初始化顺序表
void InitList(SqList *L) {
    L->length = 0;
}

// 尾部插入元素
void InsertTail(SqList *L, int val) {
    if (L->length >= MAXSIZE) {
        printf("顺序表已满，无法插入\n");
        return;
    }
    L->data[L->length] = val;
    L->length++;
}

// 遍历打印顺序表
void PrintList(SqList *L) {
    for (int i = 0; i < L->length; i++) {
        printf("%d ", L->data[i]);
    }
    printf("\n");
}

int main() {
    SqList L;
    InitList(&L);

    InsertTail(&L, 10);
    InsertTail(&L, 20);
    InsertTail(&L, 30);

    printf("顺序表元素：");
    PrintList(&L);

    return 0;
}
