## 今日掌握的重点
1.  `int *p` 只指向单个 `int`，`p++` 只走 1 个元素
2.  `int (*p)[5]` 指向一整行，`p++` 会直接跳过一整行（5个int）
3.  `*p` 是当前行的首地址，`*p + j` 可以偏移到本行的第 `j` 个元素

// 今天写的二维数组指针遍历代码
#include <stdio.h>

int main(){
    int arr[3][5] = {
        { 1,2,3,4,5},
        {100,200,300,400,500},
        {10,20,30,40,50}
    };

    int(*p)[5] = arr;

    for (int i = 0; i < 3; i++){
        for (int j = 0; j < 5; j++){
            printf("%d ",*(*p+j));
        }
        printf("\n");
        p++;
    }
    return 0;
}
