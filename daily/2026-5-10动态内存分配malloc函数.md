## 重点
1.  动态内存：程序运行时向系统申请内存，用完手动释放，灵活不浪费
2.  动态内存存在堆里，不是栈里，核心函数都在 `<stdlib.h>`
3.  `malloc` 是堆内存申请工具，参数为字节数，返回申请到的内存地址
4.  `malloc` 不会初始化内存，返回的是脏数据
5.  申请失败会返回 `NULL`，必须判断，否则程序会崩溃
6.  用完必须 `free()` 释放，否则会内存泄漏
7.  `free` 后指针必须置 `NULL`，避免野指针问题
8.  越界写内存会破坏栈数据，导致程序运行完报错

## 今日练习代码（malloc 标准用法）
```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    // 申请能放5个int的内存
    int *arr = (int *)malloc(5 * sizeof(int));

    // 必写！判断申请成功没
    if (arr == NULL) {
        printf("内存不够，申请失败了\n");
        return 1;
    }

    // 像数组一样用就行
    for (int i = 0; i < 5; i++) {
        arr[i] = i + 1;
    }

    // 用完必须释放
    free(arr);
    // 释放后指针置空，防止野指针
    arr = NULL;

    return 0;
}
