## 2026年5月14号数据结构顺序表

管理一个动态数组

E是一个指针指向malloc申请出的内存空间
capacity是当前数组的最大容量
size为有效的函数个数

```c
struct list{
	E* array;
	int capacity;//定义数组的元素长度
	int size;//定义这个数组现在有几个元素
};
```

这个函数的作用是初始化顺序表,首先把 capacity 设置为10，表示当前顺序表默认最多存10个元素.然后使用 malloc 在申请一块内存，大小为 sizeof(E) * capacity，如果 E 是 int，那么默认会申请 40 字节空间。如果 malloc 返回 null，说明内存申请失败，返回0。最后把 size 设置为0，表示当前表还没有存放有效元素，然后返回1表示成功。

```c
bool initList(struct list *list) {

	list->capacity = 10;//
	list->array = malloc(sizeof(E) * list->capacity);//开辟一个空间大小为单个E数据类型*capacity
	if (list->array == NULL)//开辟空间为null即为失败
	{
		return 0;
	}
	list->size = 0;
	return 1;
}
```

这个函数用处是在指定的位置插入元素,首先判断 index 是否合法,如果当前元素数量已经等于 capacity，说明数组已经满了，需扩容,扩容时使用 realloc 重新申请更大的内存空间，新空间为原来的1.5倍,扩容成功后，从数组最后一个有效的元素开始，依次向后移动，给新元素位置。最后把 element 插入到 index-1 对应的真实数组下标位置， size++ 表示当前有效元素数量加一个

```c
bool insertList(struct list* list,E element,int index) {
	if (index < 1 || index > list->size + 1) //判断
	{
		return 0;
	}
	if (list->size == list->capacity)//判断是否超出数组元素
	{
		int newCapacity = list->capacity + (list->capacity >> 1);//扩容
		E * newArray = realloc(list->array, newCapacity * sizeof(E));
		if (newArray == NULL)//判断是否扩容成功
		{
			return 0;
		}
		list->array = newArray;
		list->capacity = newCapacity;
	}
```

这个函数的作用是删除指定位置的元素,首先判断 index 是否合法,如果位置合法，就从 index-1 开始，把后面的元素依次向前覆盖，整体左移一位。例删除20，是后面的30覆盖20,最后执行 size--，表示当前元素数量减少一个

```c
bool deleList(struct list* list, int index) {

	if (index < 1 || index > list->size ) //判断index是否合法
	{
		return 0;
	}
	
	for (int i = index -1 ; i < list->size - 1; i++)
	{
		list->array[i] = list->array[i + 1];// 依次覆盖前一个元素

		
	}
	list->size--;//删除替换的元素
	return 1;
}
```

这个函数的作用是遍历并打印顺序表中的所有有效元素

```c
void printfList(struct list* list) {
	
	for (int i = 0; i < list->size; i++)
	{
		printf("%d",list->array[i]);
		printf("\n");
	}
}
```

main函数展示如何使用

```c
int main() {

	struct list mylist;
	
	if (initList(&mylist)) {

		for (int i = 1; i < 11; i++)
		{
			insertList(&mylist, i * 10, mylist.size + 1);
			
		}

		printfList(&mylist);

		deleList(&mylist, 0);

		printf("----------------------\n");

		printfList(&mylist);

		printf("%d", mylist.size);
	}
	else
	{
		printf("顺序表初始化失败,无法启动");
	}

}
```
